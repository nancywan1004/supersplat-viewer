蓝标 = CPU（主线程） 绿标 = GPU

换档流水线 + CPU / GPU 分工

一句话 bake = CPU 重活（gapMs）；渲染 = GPU 轻活（gpu ~16ms）。uniqueBlocks 衡量 CPU bake 规模，drawCalls 衡量 GPU 渲染批次——两码事。

各阶段 CPU / GPU

阶段端说明
换 LOD / syncCPUviewer refinement，~1ms
改 interval + MemBlockCPU触发 bake
assignSplatOffsets ★CPUgapMs 热点，按 splat 线性
staging + writeBufferCPU 发起计入 gapMs，非 drawCall
Work BufferGPU 存VRAM
Cull / Sort / forwardGPUdrawCalls 在这

指标量什么关系
