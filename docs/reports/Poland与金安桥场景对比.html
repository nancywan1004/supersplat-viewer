指标落在哪

指标量什么端 / 关系
gapMsCPU bake 残差★ 卡顿主因
cpu.renderMsCPU render 采样部分 bake 计入
gpu.totalMsGPU 全 passPoland 慢帧 ~16ms，不是主因
uniqueBlocksbake 规模（CPU 侧）与 gapMs 最相关
drawCallsGPU 渲染批次弱相关，≠ bake 次数
一句话 bake = CPU 重活（gapMs）；渲染 = GPU 轻活（gpu ~16ms）。uniqueBlocks 衡量 CPU bake 规模，drawCalls 衡量 GPU 渲染批次——两码事。
