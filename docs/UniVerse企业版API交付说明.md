# UniVerse企业版API交付说明

# 一、准备工作

如需使用UniVerse企业版API，请先联系我们：

1. 开通UniVerse企业版账号

2. 购买企业账号的AccessId和AccessSecret用于API鉴权

联系方式：见平台“联系我们\-技术支持”账号，或发送邮件至public@bdnrc\.org\.cn



# 二、快速启动

## 三维重建

目前以REST API接口形式开放，前/后端项目皆可调用，主要用于重建项目的创建与进度查询。

### 版本V1\.0

具体步骤（请配合***Universe后端重建服务API接口文档***做参考）：

1. 配置环境变量AccessId和AccessSecret

2. 调用接口获取API token（参考文档2\.1申请Token）

    1. token默认**7200秒（2小时）**过期，需引入过期refreshToken机制（参考文档2\.2Token刷新）

3. 调用接口创建重建任务（参考文档3\.1提交任务）

4. 调用接口查看重建任务状态（参考文档3\.2查看任务详情）

5. 补充说明：

    1. 提交的文件格式需注意：

        1. **图片必须采用zip包**的格式（不支持单张图片），根目录需要直接包含图片，或者存储在根目录的images文件夹下

        2. URL中**不可掺杂UTF\-8编码**（例如：%E9%A6%96%E9%92%A2%E5%9B%AD%E9%87%91%E5%AE%89%E6%A1%A5，浏览器直接复制会携带，需还原为原始中文文件名）

## 场景浏览与编辑

目前支持作为JSLoader的方式嵌入到H5网页中，适配多种前端架构。主要用于3DGS场景的浏览与编辑。

### 版本V1\.0

具体步骤（请配合***UniVerse 场景编辑器SDK接口文档***做参考）：

1. 配置环境变量AccessId和AccessSecret

2. 调用接口获取API token（同三维重建中接口）

    1. token默认**7200秒（2小时）**过期，可能需引入过期refreshToken机制

3. 初始化Universe Studio（参考文档2\.最小接入）

    1. 配置Universe Studio地址：https://universe\-api\.bdnrc\.org\.cn

    2. 选择浏览/编辑模式并连接

4. 加载模型（参考文档3\.加载模型）

    1. 外部OSS URL：模型地址（sog/ply/splat/lod\-meta\.json）必传，settings\.json配置文件选传。

        1. **补充说明**：用户需给外部CDN配置好跨域（允许universe\-api\.bdnrc\.org\.cn域名访问或者放开CORS限制）即可

    2. 本地上传文件：

        1. 支持项目zip包解压后的文件夹

        2. 支持单个模型文件（sog/ply/splat）

    3. 选择好文件后加载即可

5. 浏览/编辑模型

    1. 浏览：支持环绕/漫游相机模式切换、重置视角、场景内容的显隐等。

    2. 编辑：

        1. 按模块区分，支持GS编辑、资产放置、场景标注放置、环境设置（光照、阴影、辉光等）、相机设置（路径动画、碰撞等）、场景特效、场景滤镜和天空盒设置共八个模块的能力。

        2. 额外支持：预览模式（gizmo隐藏、模拟纯浏览模式行为）、扬声器开关、重置视角、设置默认初始视角和重置设置的能力。

    3. 补充说明：注意**切换浏览/编辑模式**时需要**销毁并重新初始化Studio。**

6. 导出项目（参考API文档4\.保存、下载和退出）

    1. 导出时默认以多个文件打包为zip包的形式，会包含模型文件（content）、配置文件\(settings\.json\)和第三方素材（例如：放置的三维模型资产）；LOD大场景因其包含多个sog文件，整体下载时间可能较久。
