# UniVerse 企业版 API 交付说明

更新日期：2026-10-20。本说明提供开通、重建和场景浏览编辑的接入路径；后端尚未确认的内容在文末单独列出。

## 一、开通与交付内容

请先开通 UniVerse 企业版 API 权限，并联系平台获取 `AccessId` 和 `AccessSecret`（重建接口文档中密钥参数名为 `secretKey`）。授权范围及购买方式以平台开通结果为准。

联系方式：平台“联系我们－技术支持”，或 [public@bdnrc.org.cn](mailto:public@bdnrc.org.cn)。

| 能力               | 客户接入方式                                      | 配套资料                                   |
| ------------------ | ------------------------------------------------- | ------------------------------------------ |
| 三维重建           | 客户服务端调用 REST API，提交任务并查询进度及结果 | 重建 REST 接入说明、OpenAPI 接口 PDF       |
| 场景浏览与编辑     | 客户网页通过 Studio SDK 嵌入托管 Studio           | SDK 使用说明、快速接入、SDK ZIP、在线 Demo |
| 模型与相机轨道编辑 | 由 Studio 打开 Editor 并接收编辑结果              | Editor 能力与边界说明                      |

开发者平台位于 UniVerse 网站左侧“API”入口（`/ability/api`），集中提供上述文档、下载及示例。SDK 通过 ZIP 交付，当前包版本为 `0.1.0`；文档和 REST 接口各自具有版本，不能用文档版本代替 SDK 版本。

## 二、鉴权准备

`AccessSecret` 必须保存在客户服务端；签名、Token 申请和刷新也由客户服务端完成。不要把密钥放进前端环境变量、网页、公开代码或 SDK 配置。客户网页只取得当前接入所需的有效 `accessToken`。

- 重建 REST 请求头使用 `Authorization: Bearer <accessToken>`。
- Studio SDK 的 `accessToken` 参数只传原始 Token，不加 `Bearer `。
- Token 有效期按申请/刷新响应的 `expiresIn` 处理，现有重建文档示例为 7200 秒。
- 重建刷新接口使用旧的 Access Token 和 Refresh Token；成功后保存新的 Token 对。Refresh Token 会轮换，旧值不能重复使用。
- Studio SDK 不负责申请、刷新或动态更新 Token。取得新 Token 后，需要先处理未保存内容，再销毁旧实例并重新创建。
- 接入凭证的适用产品和菜单权限，以平台开通结果为准。重建 Token 与 Studio Token 的最新共用范围待后端确认，请勿自行假定任意 Token 可用于全部产品。

## 三、三维重建 REST API

请先阅读开发者平台中的“三维重建 REST API”，并下载配套 `OpenAPI-接口-v1.0.1-20260909.pdf`。现有 PDF 作为版本化参考保留，未确认事项以本说明文末清单为准。

1. 客户服务端根据接口文档计算签名并申请 Token。
2. 将源文件放到重建服务可以通过互联网读取的完整 URL；文件内容、大小和采集类型需满足实际开通要求。
3. 调用提交任务接口，保存返回的 `taskId` 和 `requestId`。
4. 通过任务详情查询 `status`、`progress`、`errorMsg` 和 `models`，在成功或失败后结束轮询。轮询频率待后端确认。
5. 需要任务历史时使用任务列表接口的分页、状态筛选。

提交任务会启动重建业务，实际配额和计费以平台开通规则为准。当前说明页和在线阅读不会主动提交任务。

图片 ZIP 要求、ZIP 内目录结构和 URL 编码特殊限制尚未与现有接口示例对齐，见文末“待后端确认”。在口径确定前，不提供猜测性的文件转换或解码方案。

## 四、场景浏览与编辑 SDK

客户网页引入 `studio-sdk.js`（ESM）或 `studio-sdk.global.js`（全局脚本），连接我方托管 Studio；客户无需自行部署 Studio、Viewer 或 Editor。

- Studio：<https://universe-api.bdnrc.org.cn/>
- 在线 Demo：<https://universe-apidemo.bdnrc.org.cn/demo/index.html>
- 完整参数、类型、示例代码和下载包见开发者平台“Studio SDK 使用说明”和“下载与示例”。

### 1. 初始化与加载

1. 在客户网页放置有明确高度的容器，用有效的原始 Token 调用 `createStudio()`。
2. 等待 `client.ready` 后调用 `client.load()`。
3. URL 加载支持 SOG、PLY、SPLAT，或将 LOD 的 `lod-meta.json` 传给 `modelUrl`；`settingsUrl` 可选。
4. 本地通过文件选择器传入 `File[]`，支持普通模型和完整项目目录；ZIP 需先解压，保留目录层级。LOD 需包含唯一入口和全部分片。本地选择/加载本身不代表已上传至客户存储。
5. `mode: 'view'` 用于浏览，`mode: 'edit'` 用于编辑。切换模式时先处理未保存内容，再销毁并重建实例；销毁不会自动保存。

### 2. 跨域与资源访问

CORS 配置在提供模型、配置和素材的文件服务器上。需允许实际读取文件的 Studio、Viewer、Editor 来源，不能只配置客户网页来源。当前正式托管来源为：

| 读取方 | CORS 来源                              |
| ------ | -------------------------------------- |
| Studio | `https://universe-api.bdnrc.org.cn`    |
| Viewer | `https://3dgs-viewer-api.bdnrc.org.cn` |
| Editor | `https://3dgs_editor.bdnrc.org.cn`     |

测试组件或自定义托管地址需按其实际来源另行配置；完整配置说明见 SDK 文档。

LOD 描述文件与所有分片、配置引用的资源都应可访问；视频文件服务需支持 Range 请求。SDK 不会给文件请求自动附加客户的自定义 HTTP 头，私有资源可使用有效的签名 URL；不要自行整体解码或改写签名链接。

### 3. 浏览和编辑能力

浏览支持环绕/漫游、重置视角和场景内容显隐等操作。Studio 编辑能力包括 GS 编辑、资产、标注、环境、相机、特效、滤镜和天空盒；实际显示和可用项受菜单授权、资源配置及 Viewer 能力影响。

资产库通过客户提供的 `assets.getAssetList()` 和 `assets.getAssetDetail()` 接入，未配置时不可用。天空盒、特效预览可通过 `materials` 配置，未配置时使用内置公开素材。

Editor 由 Studio 管理，提供模型及相机轨道编辑；普通客户不需要重复接入另一套 Editor SDK。宿主模型输入为单个 File/URL，修改后的模型回传格式为 PLY；不能把 Studio 支持 LOD 加载理解为 Editor 可直接编辑完整 LOD 目录。

### 4. 完成、保存与下载

| 操作                                    | 结果                                                      |
| --------------------------------------- | --------------------------------------------------------- |
| Editor 中“完成”                         | 将本轮编辑结果交回 Studio，不代表客户服务端已持久保存     |
| `client.save()`，未配置 `saveArtifacts` | 生成项目 ZIP 并发起浏览器下载                             |
| `client.save()`，配置了 `saveArtifacts` | 客户回调完成文件上传、引用更新和配置/版本保存，再返回成功 |
| Studio 工具栏“下载”                     | 始终下载项目 ZIP，不调用客户保存回调                      |
| `client.destroy()`                      | 清理实例，不自动保存                                      |

ZIP 包含配置和实际返回的文件，并保留已有远程 URL 引用；不能承诺自动包含所有第三方素材或完全离线使用。大规模 LOD 包含多个分片，下载时间取决于资源大小及网络。

`save()` 返回 `download-started` 仅表示开始下载；返回 `saved` 表示客户保存回调报告成功。需要通过 SDK 重新打开客户保存结果时，回调还需返回有效的 `reopen.modelUrl` 和 `reopen.settingsUrl`。完整结构见 SDK 类型和示例。
