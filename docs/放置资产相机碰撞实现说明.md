# 放置资产相机碰撞实现说明

> 对场景中已放置的 **mesh / gaussian** 放置项做 AABB 相机碰撞（推开、不穿模），含调试线框与 settings 持久化。

## 1. 能力概览

| 项 | 说明 |
|----|------|
| 碰撞对象 | 所有可见 **mesh / gaussian** 放置项（非仅选中项） |
| 相机模式 | **Fly**、**Orbit** 均接入 `sceneAssetCollisionResolver` |
| 总开关 | **`settings.collision.enabled`**：同时调度场景 collision mesh（Walk/Fly）与放置资产 AABB（Fly/Orbit） |
| 生效时机 | 总开关开启且 **`collisionActive(global)`**（Viewer 或编辑 **预览**）；纯编辑态不推开 |
| 碰撞体 | 世界 AABB；相机用半径 **`SCENE_ASSET_CAMERA_COLLISION_RADIUS`**（= `DEFAULT_CAMERA_COLLISION_RADIUS`，默认 **0.09m**）的球体与 AABB 求交推开；可用 `settings.collision.cameraRadius` 覆盖（0.08–0.5） |
| 复合碰撞 | 多资产 → **`SceneAssetMultiAabbCollision`**；单资产 → **`SceneAssetAabbCollision`** |

## 2. 缩放模式（autoFit 与手动 XYZ 互斥）

- **`autoFit: true`**：仅用自动贴合系数，**忽略**面板高斯/Mesh XYZ 滑条。
  - **高斯**：局部 gsplat AABB × 实体 scale，与世界 AABB 各轴对比，收紧明显偏大的轴（`clampAutoFitFactor` 约 **0.55–1.0**）。
  - **Mesh**：世界渲染 AABB 各轴半长与几何平均半长对比，收紧明显偏长轴（启发式，无单独局部盒）。
- **`autoFit: false`**：仅用 **高斯 / Mesh 各向 XYZ** 滑条（**50%–150%**，相对渲染包围盒半轴）。
- UI：开启 autoFit 时隐藏手动 XYZ 面板（`camera-settings-ui.ts`）。

### 默认值（`DEFAULT_SCENE_ASSET_COLLISION_SCALE`）

| 字段 | 默认 |
|------|------|
| `gaussian` | x/y/z **85%** |
| `mesh` | x **57%**，y/z **85%** |
| `autoFit` | **false** |

## 3. 状态与类型分层

| 层级 | 类型 | 位置 |
|------|------|------|
| 入库 | `SceneCollisionSettings`（`url` + **`enabled` 总开关** + `scale` 仅放置资产） | `schemas/v2-custom.ts` → `settings.collision` |
| 会话 | `SceneAssetCollisionRuntimeState` = Settings + **`debugVisual`** | `types.ts`（与 `EffectsRuntimeState` 同级；**不在 v2-custom**） |
| observe | `state.sceneAssetCollisionRuntimeState` | `index.ts` 初始 key |

- **`debugVisual`**：仅会话态，**不入 settings.json**；绿线框显示**最终碰撞盒**（与推开一致，含 autoFit 或 XYZ）。
- 持久化：`persistCollisionToSettings` / `applySceneAssetCollisionFromSettings`；`settings-serialize` 只写入 `collision`（含 `url` / `enabled` / `scale`），不再输出 `sceneAssetCollision`。

## 5. 主要 API

- `getCameraCollisionManager(global)`：`collisionEnabled` / `setEnabled` / `collisionActive` / `getCollision` / `activeCollision` / `getSceneMeshEntity` / `ensureSceneMeshLoaded` / `start`

## 6. 缓存失效

放置、变换、显隐、`sceneAssets:*` 等事件触发 `SceneAssetCollisionRuntime.markDirty()`，下一帧重建碰撞复合体。

## 7. 场景碰撞配置与 Universe 生成（阶段二 PR-2）

| 配置 | 说明 |
|------|------|
| `settings.collision` | 碰撞统一配置（GLB/voxel URL、总开关、放置资产 AABB 缩放）；类型 `SceneCollisionSettings`，见 `schemas/v2-custom.ts` |
| `settings.collision.url` | 资源地址；**低于** URL 参数 `?collision=` / `?voxel=`；Universe 生成后写成相对路径（如 `assets/collision.glb`），随 `PROJECT_SAVE` 进 zip / OSS sidecar |
| `settings.collision.enabled` / `scale` | 物理碰撞总开关 + 放置资产 AABB 缩放 |

- **URL 来源**：[`scene-collision-source.ts`](../src/collision/scene-collision-source.ts)（`resolveCollisionUrl`、`ensureCollisionUrl`），负责 URL 参数 / settings / Universe 产物的选择与写回（参数优先）。
- **Universe API**：[`universe/collision-mesh-service.ts`](../src/universe/collision-mesh-service.ts) 调用网关 `POST /conversion/voxel-collision/jobs`（`{ modelUrl, projectId }`）立即返回 `jobId`，再 `GET /conversion/voxel-collision/jobs/:jobId` 轮询至 `succeeded` 取 **`data.url`**；轮询超时从 **`running`** 起算（不含排队）；生成中出站 **`SCENE_MESH_LOAD_PROGRESS`**。无现成 URL 时生成并写回 settings；**已有 URL 加载失败且具备凭证时** `forceRegenerate` 再生成一次，`modelUrl` 为 `config.contentUrl`；鉴权见 [`universe/service.ts`](../src/universe/service.ts)。
- **GLB 加载**：[`scene-mesh-loader.ts`](../src/loaders/gltf/scene-mesh-loader.ts) 仅负责 `loadSceneMesh`（一次请求产出 `MeshCollision` + 接影 `Entity`）。
- **门控与消费方绑定**：[`CameraCollisionManager`](../src/collision/camera-collision-manager.ts) 按需触发上述来源解析/加载；加载失败可回落重新生成；voxel [`voxel-collision.ts`](../src/collision/voxel-collision.ts)。

## 8. 已知限制

- **Fly** 用 `SphereMover` 从上一帧安全点扫掠到本帧落点，薄墙停在表面；穿模则退回上次清空位置。Walk 在单步水平位移大于胶囊半径时拆成多段 `queryCapsule`。
- **Walk** 模式尚未接入放置资产 AABB（Fly/Orbit 已接；若要做可复用 fly 二次 `querySphere`）。
- 协议字段为 **`enabled`**（非历史 `userEnabled`）；按项目规则**不保留旧字段兼容**。
