# 局部亮度调节实现说明（基于 2D 纹理图集）

本文档说明「已提交区域局部亮度」的实现原理：用 3D 体积烘焙到 2D 图集纹理，shader 一次采样得到 mask，无点数上限且每 splat O(1)。

---

## 0. 在「局部柔光」基础上的实现思路对比

**局部柔光（Bloom）与局部调亮/调暗共用同一套绘制与存储流程，仅在「如何用这些点驱动效果」上不同。**

### 共用部分（输入与持久化）

1. **用户在屏幕上绘制**：通过 Picker 的 ray casting 得到 3D 世界坐标。
2. **世界坐标存入点列表**：每个点包含「位置 + 影响半径」，由 `WorldSpaceBloomData` 管理（当前绘制点 + 已提交点）。
3. **持久化**：参与 bloom / 调亮调暗的点（位置、半径）会写入 `settings.json`（如 `worldSpacePoints`、`committed`、`committedBrightness`）。

### 局部柔光（Bloom）的实现思路

4. **Shader 中判断**：对每个 splat，判断其世界坐标是否落在**任意** bloom 点的影响范围内（或通过 2D mask 等方式标记）。
5. **后处理**：被标记为「参与 bloom」的区域，在后处理阶段应用 bloom 效果（发光、模糊等）。

### 局部调亮/调暗的实现思路（在同上 1–3 的基础上）

4. **不**在 shader 里对每个 splat 用 for 循环遍历所有已提交点（否则会有 64 点上限、每 splat O(N) 等问题）。
5. **改为「3D 亮度场 → 2D 图集」**：
   - CPU 端：把**已提交点**（位置 + 半径）烘焙成 3D 亮度场（64³ 体素），再打包成 **64×4096 的 2D 纹理图集**，并算好世界空间 AABB。
   - Shader 端：每个 splat 用**自己的世界坐标**换算成体积内归一化坐标，再映射到 2D UV，**只做一次 2D 纹理采样**得到 `committedMask`，然后 `color *= 1 + uCommittedBrightness * committedMask`。
6. **效果**：O(1) 每 splat、无点数上限，支持任意数量的局部调亮/调暗区域；已提交点仍与局部柔光共用同一套列表并一起存进 `settings.json`。

---

## 1. 整体思路

- **数据来源**：`WorldSpaceBloomData` 的已提交点列表（世界坐标 + 半径）和统一亮度系数（-1～1）。
- **烘焙**：CPU 把 3D 亮度场烘焙成 64³ 体素，再打包成一张 **64×4096 的 R8 2D 纹理图集**。
- **渲染**：每个 splat 用世界坐标换算成体积内归一化坐标，再映射到 2D UV，**一次 texture2D 采样**得到 `committedMask`，最后 `color *= 1 + uCommittedBrightness * committedMask`。
- **2D 纹理采样**：根据给定的 UV（通常 [0,1]²）在纹理上找到对应像素（texel），按过滤方式（如双线性）得到颜色或标量值。

---

## 2. 数据流

| 阶段 | 位置 | 说明 |
|------|------|------|
| 数据源 | `WorldSpaceBloomData` | `getCommittedPoints()`（position + radius）、`getCommittedBrightness()` |
| 烘焙 | `committed-brightness-volume.ts` | 根据 AABB 在 64³ 网格上算每个体素的 mask，写入 64×4096 纹理 |
| 同步 | `bloom.ts` | Set / 加载配置时调用 `syncCommittedToNightMode()`，仅必要时重建纹理 |
| 传参 | `night-mode.ts` | `setCommittedBrightnessVolume(texture, aabbMin, aabbMax, brightness)`，每帧设 uniform |
| 采样 | NightMode 的 GLSL/WGSL | 世界坐标 → 归一化 n → 体素索引 → UV → texture2D → 乘算 |

---

## 3. 体积烘焙（CPU）

**文件**：`src/vfx/committed-brightness-volume.ts`

- **AABB**：所有 committed 点的 `position ± radius`，再加固定 margin，得到世界空间 `aabbMin`、`aabbMax`。
- **体素 → 2D 布局**：
  - 逻辑体积：64×64×64。
  - 2D 纹理：宽 64、高 4096（= 64×64）。
  - 体素 `(ix, iy, iz)` 对应 2D 像素列 `ix`、行 `iy + iz * 64`，即索引 `ix + (iy + iz*64) * 64`。
- **每个体素**：
  - 体素中心映射到世界坐标，对每个 committed 球做距离 d、半径 r。
  - Mask：`t = 1 - smoothstep(0.5*r, 1.3*r, d)`，多球累加后 clamp 到 [0,1]。
  - 写入 R8：`pixels[idx] = round(mask * 255)`。
- **重建时机**：仅在「Set / loadWorldSpaceConfig / 首帧无纹理」时调用，避免每帧重建造成卡顿。

---

## 4. Shader 采样与应用

**世界坐标 → 体积内归一化坐标**

```glsl
vec3 size = max(uCommittedAabbMax - uCommittedAabbMin, vec3(1e-6));
vec3 n = clamp((wpos - uCommittedAabbMin) / size, 0.0, 1.0);
```

**归一化坐标 → 体素索引 → 2D UV**

```glsl
float ix = floor(n.x * 64.0);  // 0..63
float iy = floor(n.y * 64.0);
float iz = floor(n.z * 64.0);
ix = min(ix, 63.0); iy = min(iy, 63.0); iz = min(iz, 63.0);
float u = (ix + 0.5) / 64.0;
float v = (iy + iz * 64.0 + 0.5) / 4096.0;
```

**一次 2D 采样 + 乘算**

```glsl
float committedMask = texture2D(uCommittedBrightnessVolume, vec2(u, v)).r;
color.rgb *= 1.0 + uCommittedBrightness * committedMask;
```

- `committedMask` ∈ [0,1]：该位置受已提交亮度影响的程度。
- `uCommittedBrightness`：整体亮度系数（正=提亮，负=调暗）。

---

## 5. 与 Bloom Brush 的配合

- **已提交区域**：始终只由体积纹理 + `uCommittedBrightness` 决定，与是否开启 Bloom Brush 无关。
- **笔刷预览**：仅在 **未提交** 区域上叠加实时亮度；用 `committedMask < 0.2` 判定「明确未提交」，避免体积边缘重复乘算（原先 0.01 过松会导致进入笔刷更亮）。
- **进出一致**：笔刷分支内不 `return`，笔刷内外都继续做 nightFade，保证进/出 Bloom Brush 时同一区域亮度一致。

---

## 6. 关键参数与效果

| 项 | 值/说明 |
|----|--------|
| 体积分辨率 | 64³ |
| 2D 纹理尺寸 | 64×4096，R8 |
| Falloff | smoothstep(0.5r, 1.3r, d)，外扩 1.3r 使退出笔刷后亮区不明显变小 |
| 未提交阈值 | committedMask < 0.2 才乘预览亮度 |
| 成本 | 每 splat 一次 2D 采样 + 一次乘算，O(1)，无 64 点上限 |
