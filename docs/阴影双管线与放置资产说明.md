# 阴影双管线与放置资产说明

## 1. 架构（A / B）

| 管线 | 机制 | 谁参与 |
|------|------|--------|
| **A** | 引擎 `shadow map` + `receiveShadows` / `shadowCatcher` | 放置 **mesh**（三角面接影） |
| **B** | `shadowMaskCamera` 写 `shadowTex` → `postrender` 全屏 `(1-R)*darken` | **主场景高斯** + 地面/接影区域 |

前置能力：GLB 型 URL `?collision=`（`hasShadowCapability`）。手动开关：`postEffectSettings.shadow.enabled`。

**主场景高斯**：`castShadows` 恒 **false**（不参与 GSPLAT_SHADOW，避免与放置高斯 cast 状态不一致）。

**放置高斯**：`castShadows` 随 `shadow.enabled`（可进 shadow map）。

**放置 mesh**：`castShadows` + `receiveShadows` 随 enabled；B 叠影由 **`ShadowReceiverOccluder`** 深度预写遮挡。

**image / video**：`receiveShadows: false`（unlit 卡片）；B 叠影同样由 **`ShadowReceiverOccluder`** 处理。

## 2. B 管线「透影 / 横切」与 exclude mask

B 无深度测试，会在放置资产屏幕像素上叠地面阴影 → 假阴影/横切。

**做法**（`shadow-apply-exclude-mask.ts`）：

- 层 **`PlacedMeshExclude`**：仅 **exclude 相机**（priority 1）渲染；**主相机 layers 不含此层**。
- **mesh / image / video**：在 `ShadowReceiverOccluder` 层做 depth-only 预写，`shadowMaskCamera` 随后渲接影层时由 GPU 深度测试裁掉被前景 render 资产挡住的接影像素；**不再**挂 `PlacedMeshExclude`、不再写 R 通道 mask。
- **gaussian**：`PlacedMeshExclude` 层 + exclude 相机；mask-only shader 输出 **G=1**；postrender 在 **G mask 与 shadowMask 深度一致或更近** 时 `blend *= (1 - gsplatMask)`，避免轮廓投到前景放置 mesh 上仍抠洞。

叠影公式：

```text
shadowTex 已在 shadowMaskCamera 内被 render 资产深度裁剪
blend = (1 - shadowTex.r) * darken * (1 - gsplatMask)
```

调试：`postEffectSettings.shadow.debugExcludeMask = true`。

## 3. unified 花屏（引擎限制）

同一 **Layer** 内若 `gsplatPlacementsSet ≠ gsplatShadowCastersSet`（例如主高斯 `castShadows=false`、放置高斯 `true`），PlayCanvas `gsplat-director` 会拆 **forward + shadow** 双 manager → 花屏/闪烁。

**可选方案与取舍**：

| 方案 | 结果 |
|------|------|
| 主/放置 **同层 cast 全 true** | 不花屏，主高斯也投影，场景易乱 |
| **PlacedGsplat 分层** | 不花屏，但 **高斯间遮挡/排序** 按 layer 硬叠，易错乱 |
| **主/放置 cast 全 false** | 最稳；放置高斯不投影，仅 mesh 投阴影 |
| **引擎修复** | 同层部分 placement 进 shadow pass 且单 manager 稳定（需 PlayCanvas 侧） |

当前代码策略：**主 false + 放置随 enabled** + **exclude mask 修 B 透影**。

## 4. 关键文件

| 文件 | 职责 |
|------|------|
| `src/vfx/shadow/shadow-system.ts` | 门控、cast/receive 同步、reveal 后 `activateOutput` |

## 5. reveal 时序

有 Timed reveal 时阴影管线 **defer 到 `revealComplete`** 再 `activateOutput`，避免开场叠影/接影干扰。
