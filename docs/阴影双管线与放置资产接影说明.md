# 阴影双管线与放置资产接影说明

## 1. 架构概览

本 Viewer 阴影能力依赖 GLB 型 URL `?collision=`（`hasShadowCapability`），并由 `postEffectSettings.shadow.enabled` 手动开关。

| 管线 | 机制 | 谁参与 |
|------|------|--------|
| **A** | 引擎平行光 shadow map + `receiveShadows` | 放置 **mesh**（三角面接影） |
| **B** | `shadowMaskCamera` 写 `shadowTex` → `postrender` 全屏叠黑 | **场景主高斯** + 地面（接影 GLB/平面） |

实现分散在：

- `src/vfx/shadow/shadow-system.ts` — 策略、cast 同步、reveal 门控
- `src/vfx/shadow/shadow-catcher.ts` — 接影几何（ShadowMask 层）
- `src/vfx/shadow/shadow-apply.ts` — B 管线 postrender quad
- `src/vfx/shadow/shadow-apply-exclude-mask.ts` — 放置资产 B 叠影排除 mask

更完整的 Demo 对照见 `src/vfx/shadow/SHADOW_DEMO_对比与配置.md`。

## 2. castShadows 策略（当前代码）

| 资产 | castShadows | 接收阴影 |
|------|-------------|----------|
| 场景主高斯 | **恒 false** | B（全屏叠影） |
| 放置高斯 | `shadow.enabled` | B；自身像素由 exclude mask 排除 |
| 放置 mesh | `shadow.enabled` | A（`receiveShadows`）+ **ShadowReceiverOccluder** 排除 B |
| 放置 image / video | 不参与引擎阴影投射 | **ShadowReceiverOccluder** 排除 B |

同步入口：`syncGsplatShadowCastingFromSettings`（`shadow-system.ts`），在放置/恢复/开关变化时调用。

## 3. PlacedMeshExclude（B 管线自接影排除）

**问题**：B 管线无深度测试，`shadowTex` 在地面变暗的屏幕区域会叠到放置资产像素上 → 假阴影/横切/透影。

**做法**：

1. 层名 `PlacedMeshExclude`：仅 **exclude 相机**（priority 1）渲染，**主相机 layers 不含此层**。
2. **mesh / image / video**：`ShadowReceiverOccluder` 层 depth-only 预写；**不**再挂 `PlacedMeshExclude`。
3. **gaussian**：`PlacedMeshExclude` 层 + exclude 相机；mask-only shader 输出 **G=1**（**勿用 alpha**：clearColor 为 `(0,0,0,1)`）。
4. postrender：`shadowTex` 已含 render 深度裁剪；`blend *= (1 - max(G,B))` 仅排除放置高斯像素。

调试：`postEffectSettings.shadow.debugExcludeMask = true` 查看 exclude RT。

## 4. unified 花屏（引擎限制）

**现象**：同一 `Layer` 内，部分 gsplat `castShadows=true`、部分 `false` 时，PlayCanvas `gsplat-director` 会拆 **forward + shadow** 双 manager，易出现花屏/闪烁。

**约束**：主高斯不投影、放置高斯要投影、且**遮挡关系正确** → 不能靠「分 Layer」简单规避（分 Layer 会破坏 unified 同层排序合成）。

**可选方向**：

- 引擎修复：`gsplatPlacementsSet` 与 `gsplatShadowCastersSet` 不等时仍稳定，或 per-placement shadow 过滤。
- 产品折中：主/放置高斯 **统一** `castShadows`（全开或全关）；或仅 mesh 投射、高斯不 cast。

相关代码：`node_modules/playcanvas/.../gsplat-director.js` → `updateConfiguration`。

## 5. 门控与时序

- **Capability**：GLB 型 `?collision=`
- **Enablement**：`shadow.enabled !== false`
- **Output**：`readyToRender` + `activateOutput`（Timed reveal 在 `revealComplete` 后挂载）

`isShadowOutputEnabled` = 上述三者同时满足。
